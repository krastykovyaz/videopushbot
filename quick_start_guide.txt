📋 ШАГ 2: ПОЛУЧЕНИЕ API КЛЮЧЕЙ
═══════════════════════════════════════════════════════════════

┌─ YOUTUBE ─────────────────────────────────────────────────┐
│ 1. Зайти: https://console.cloud.google.com/              │
│ 2. Создать проект                                         │
│ 3. Включить YouTube Data API v3                          │
│ 4. Создать OAuth 2.0 credentials                         │
│ 5. Скачать client_secret.json                            │
└───────────────────────────────────────────────────────────┘

┌─ VKONTAKTE ───────────────────────────────────────────────┐
│ 1. Зайти: https://vk.com/apps?act=manage                 │
│ 2. Создать Standalone приложение                         │
│ 3. Получить токен с правами: video, offline              │
│                                                            │
│ Простой способ получить токен:                            │
│ https://vkhost.github.io/ (OAuth для VK)                 │
└───────────────────────────────────────────────────────────┘

┌─ RUTUBE ──────────────────────────────────────────────────┐
│ 1. Зайти: https://rutube.ru/                             │
│ 2. Настройки → API → Создать приложение                  │
│ 3. Получить: client_id, client_secret, access_token      │
└───────────────────────────────────────────────────────────┘

┌─ SPOTIFY PODCASTERS (ANCHOR) ─────────────────────────────┐
│ Примечание: Spotify имеет ограниченное API               │
│                                                            │
│ Альтернативы:                                             │
│ - Используйте только YouTube + VK + Rutube               │
│ - Замените на Telegram или TikTok                        │
│ - Используйте Selenium для автоматизации                 │
└───────────────────────────────────────────────────────────┘

📋 ШАГ 3: НАСТРОЙКА СКРИПТОВ
═══════════════════════════════════════════════════════════════

Откройте нужный скрипт и найдите раздел CONFIG:

┌─ upload_youtube_spotify.py ───────────────────────────────┐
│                                                            │
│ CONFIG = {                                                 │
│     'youtube': {                                           │
│         'client_secrets_file': 'client_secret.json',      │
│         'privacy_status': 'private',  # или public        │
│     },                                                     │
│     'spotify': {                                           │
│         'api_key': 'ВАШ_API_KEY',                         │
│         'show_id': 'ВАШ_SHOW_ID',                         │
│     }                                                      │
│ }                                                          │
└───────────────────────────────────────────────────────────┘

┌─ upload_youtube_vk_rutube.py ─────────────────────────────┐
│                                                            │
│ CONFIG = {                                                 │
│     'youtube': { ... },                                    │
│     'vk': {                                                │
│         'access_token': 'ВАШ_VK_TOKEN',                   │
│         'group_id': 0,  # 0 для личной страницы          │
│     },                                                     │
│     'rutube': {                                            │
│         'client_id': 'ВАШ_CLIENT_ID',                     │
│         'client_secret': 'ВАШ_CLIENT_SECRET',             │
│         'access_token': 'ВАШ_ACCESS_TOKEN',               │
│     }                                                      │
│ }                                                          │
└───────────────────────────────────────────────────────────┘

📋 ШАГ 5: ЗАПУСК
═══════════════════════════════════════════════════════════════

Для YouTube + Spotify:
python upload_youtube_spotify.py

Для YouTube + VK + Rutube:
python upload_youtube_vk_rutube.py

┌─ ЧТО ПРОИСХОДИТ ──────────────────────────────────────────┐
│ 1. Скрипт запускается                                     │
│ 2. Начинается мониторинг папки                            │
│ 3. При появлении нового .mp4 файла:                       │
│    - Читается описание из .txt файла (если есть)         │
│    - Видео загружается на все платформы                   │
│    - Файлы перемещаются в папку processed_videos/        │
│ 4. Результаты записываются в upload_results.json          │
└───────────────────────────────────────────────────────────┘

📋 ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
═══════════════════════════════════════════════════════════════

❌ "YouTube API quota exceeded"
   → Подождите до следующего дня (лимит 10,000 единиц)
   → Одна загрузка = ~1600 единиц

❌ "VK: Access denied"
   → Проверьте права токена (video, offline)
   → Получите новый токен

❌ "Rutube: 401 Unauthorized"
   → Обновите access_token
   → Проверьте client_id и client_secret

❌ Видео не загружается
   → Подождите 5-10 секунд после копирования файла
   → Проверьте формат (должен быть .mp4, .mov, .avi, .mkv, .flv)
   → Посмотрите логи: upload_log.txt

❌ "ModuleNotFoundError"
   → Установите зависимости: pip install -r requirements.txt

📋 НАСТРОЙКА АВТОЗАПУСКА (LINUX)
═══════════════════════════════════════════════════════════════

sudo nano /etc/systemd/system/video-uploader.service

[Unit]
Description=Video Auto Uploader
After=network.target

[Service]
Type=simple
User=ваш_username
WorkingDirectory=/путь/к/скриптам
ExecStart=/usr/bin/python3 /путь/к/upload_youtube_vk_rutube.py
Restart=always

[Install]
WantedBy=multi-user.target

Активация:
sudo systemctl enable video-uploader.service
sudo systemctl start video-uploader.service

Проверка статуса:
sudo systemctl status video-uploader.service
